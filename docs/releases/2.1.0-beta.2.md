# TRON SDK 2.1.0-beta.2 Release and External Service Compatibility

Date: 2026-10-19 (Asia/Shanghai). Publication of the reviewed upto RPC fix, alignment of both packages at 2.1.0-beta.2, and external service tests using published packages were explicitly authorized. Source branch: feat/tron-official-sdk; artifact commit 8426530dc9efa0023a1f7eacdd3badc12425910c.

## Fix and versions

When required upto allowance/balance reads throw or return invalid uint256 values, the scheme returns chain_read_failed with a fixed safe message. Partial/zero settlement first revalidates the authorized maximum; failure does not broadcast. Resource sponsorship retains deferred pre-Approval allowance checks, mandatory balance reads, and revalidation after delegation. Runtime code matches independently reviewed a39d486e; this release changes only versions, dependencies, and current documentation.

Both TRON packages are 2.1.0-beta.2; the extension depends on the exact same mechanism version, and the official Core peer remains 2.28.0. Historical beta1 and 3beta1 artifacts and release records remain unchanged. Only beta was updated, not latest. This remains a migration beta requiring changes to legacy Core/HTTP/MCP and resource runtime imports; it does not claim an unchanged-source replacement for SDK2.
