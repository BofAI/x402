## 结论

五条支付链路均已跑通；不能视为所有默认配置无条件通过。
GasFree 首次在 Gateway 默认 10 秒窗口下超时，但已完成付款且没有上游交付。
通过已有配置 `X402_GATEWAY_FACILITATOR_TIMEOUT_MS=240000`，独立新测试完成了付款和交付。
资源代付首次遇到官方 `sponsor_owner_busy`，确认未付款、未广播 Approval 后，
复用原授权重试成功。能量和带宽两类资源均完整回收。

| 场景 | 实链与功能结果 |
| --- | --- |
| 普通 exact Permit2 | 402 → 签名 → 官方 verify/settle → Gateway 200，上游交付一次，USDT Transfer 1 Atomic |
| upto | 授权上限 2，实际结算 1 Atomic；verify、结算和 Transfer 通过，重放被拒绝 |
| batch-settlement | deposit 3 → voucher verify → claim 1 → settle 1 → refund 2；通道剩余可支出额为 0 |
| GasFree | 官方 `/nile` 代理及 relayer 实际结算，Gateway 200、交付一次；支付 1 Atomic，实际手续费 300000 Atomic（0.3 USDT）；使用 240 秒 Gateway 超时配置 |
| 资源代付 | 零 allowance、零能量/质押带宽、低免费带宽新 payer；签名 Approval → 双资源委托 → Approval 成功 → 支付/交付一次，双资源均回收；原授权重试 |

独立校验了 **14 笔验收相关交易**：FullNode 原交易 `contractRet=SUCCESS`，
SolidityNode 固化回执成功；普通、upto、GasFree、资源支付均有真实 USDT Transfer 事件。
14 笔包含 4 笔 batch 交易、Approval、4 笔资源委托/回收以及首次超时但已成功的 GasFree 交易，
不包含钱包准备交易。官方按交易查询均只返回一条成功记录；资源原 nonce 也只有一次成功。
普通和资源场景的错误签名没有交付；普通、upto、资源的重放均被拒绝。

## 两次异常与对账

- **GasFree 10 秒超时**：Gateway 504，上游交付 0；官方实际成功结算 nonce 62，
  链上回执与 USDT Transfer 均成功，GasFree 当前 nonce 增至 63。
  原请求没有重发，也没有声称自动补交付。随后显式采用 240 秒配置，
  新 nonce 63 的独立测试完成交付。Gateway 默认 10 秒行为未修改；接入 GasFree 时需配置足够的
  Facilitator、客户端和入口响应等待时间。发布 SDK 本身不能修复已付款后超时的交付恢复问题。
- **资源 owner busy**：官方 settle HTTP 503、`Retry-After: 15`，Gateway 返回 502。
  按原 nonce 查询只有 `sponsor_owner_busy` 失败记录，原 Approval 无链上交易，allowance 仍为 0，
  官方 verify 仍有效。等待后重新创建本地 Gateway，使用完全相同的原始签名授权和 Approval 完成支付。
  独立比较两次原始请求完全相等；未生成替代 nonce，最终仅一次成功结算和交付。

## 边界与复现

普通、GasFree、资源通过本地已升级 Gateway 的真实 HTTP 与测试上游；upto、batch
通过 SDK 对官方 Facilitator HTTP 直接验证。Catalog 公网部署不属于本轮实链测试。
付款人与收款人为测试钱包自身，已核对真实 Transfer 事件；没有声称验证商家跨账户到账。
Gateway 默认配置下 GasFree 的已付款未交付问题仍存在，资源 busy 也没有新增自动重试实现。

官方 `/health` 为 200，`/supported` 声明对应 Nile 支付方式，`/version` 返回 404。
官方部署的 SDK/build 版本未知。本轮证明发布版客户端对官方当前部署兼容，
不能证明本地 beta.2 Facilitator 已部署，也未对官方注入 upto RPC 故障。
beta.2 的 RPC 异常明确拒绝行为仍以已记录的本地 HTTP 故障回归为证。
未测试主网、EVM 实际广播、官方服务重启或私有资源账本恢复。

使用 Facilitator 隔离检出的 `test/nile-official-compat.mjs` 和
