## Two failures and reconciliation

- **GasFree 10-second timeout:** Gateway returned 504, with zero upstream deliveries. Official settlement of nonce 62 succeeded; the receipt and USDT Transfer succeeded, and the current GasFree nonce advanced to 63. The original request was not resent, and no automatic delivery recovery was claimed. A subsequent independent test with new nonce 63 and an explicit 240-second configuration delivered successfully. Gateway's default 10-second behavior was unchanged at that point. GasFree integrations need sufficient Facilitator, client, and ingress response waits. Publishing the SDK alone cannot fix delivery recovery after a paid timeout.
- **Resource owner busy:** Official settle returned HTTP 503 and `Retry-After: 15`; Gateway returned 502. The original nonce query showed only a `sponsor_owner_busy` failure record, Approval had no on-chain transaction, allowance remained 0, and official verify was still valid. After waiting, a recreated local Gateway completed payment with the exact same signed authorization and Approval. Independent comparison confirmed identical original requests; no replacement nonce was generated, and only one settlement and delivery succeeded.

## Boundaries and reproduction

Ordinary, GasFree, and sponsored payments used real HTTP through the locally upgraded Gateway and test upstream; upto and batch used SDK calls directly to official Facilitator HTTP. The public Catalog deployment was outside this live-chain test. Test wallets paid themselves; real Transfer events were checked, without claiming merchant payment across distinct accounts. At this stage Gateway's default GasFree paid-without-delivery issue remained, and no automatic resource-busy retry implementation had been added.

Official `/health` returned 200, `/supported` advertised the corresponding Nile payment methods, and `/version` returned 404. The official deployment's SDK/build version is unknown. This run proves published-client compatibility with that deployment, not deployment of the local beta.2 Facilitator. No upto RPC fault was injected into the official service; beta.2 fail-closed behavior is supported by the recorded local HTTP fault regressions. Mainnet, live EVM broadcasts, official service restarts, and private resource ledger recovery were not tested.

Use the Facilitator isolated checkout's `test/nile-official-compat.mjs` and commands in `test/README-sdk3-compat.md`; GasFree additionally requires the 240-second variable above. After timeout/owner busy, reconcile the original txID, nonce, ledger, and allowance first. Do not blindly rerun and create a replacement payment. Private recovery requests and wallet keys are stored in restricted directories outside Git; public evidence contains no credentials or signed authorizations.
