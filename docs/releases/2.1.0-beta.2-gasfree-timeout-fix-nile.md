# GasFree Default Timeout Fix, Nile Retest, and Code Review

Date: 2026-10-19. Gateway fix commit `af019c2efc56bc91ec1663cfe0470d17c7dcd572`, baseline `1dcd07a7626dbc06f25a03c0a43b83a713db7994`. Both SDK packages remained npm registry `2.1.0-beta.2`, with Core `2.28.0` and Agent Wallet `3.0.0`. The SDK was not republished, and external services were not deployed.

## Fix outcome

TRON `exact_gasfree` verify and settle now each use a separate timeout budget, defaulting to `max(240000, X402_GATEWAY_FACILITATOR_TIMEOUT_MS)`, including the complete response body. `X402_GATEWAY_GASFREE_TIMEOUT_MS` explicitly overrides this, including shorter values. The budget is selected from the actually matched payment requirements, supporting providers with mixed Exact/GasFree routes. Ordinary Exact, resource sponsorship, and inbound body/header windows retain their semantics. GasFree no longer requires increasing the global timeout to wait for settlement.

This fixes premature termination at the default ten seconds. It does not add an automatic delivery recovery state machine. Explicit short overrides, prolonged failures, client disconnection, or process exit can still leave settlement unknown; a 504 alone must not trigger a replacement payment.

## Resource observation failure and subsequent confirmation

Resource payer: `TSL8Ru7GdbHoCxfXfaPNMDTRkdW1cdWnnV`; owner: `THuJK6PNaXibaQhxUdqUXczU57Y8EKhpex`. Delegated stake was 461966933 SUN for ENERGY and 601873881 SUN for BANDWIDTH; both were ultimately reclaimed in full.

**Reclamation was not observed within the original short window; the script failed with `reclaim not observed yet`.** That initial report was retained. Payment and upstream delivery had already succeeded, so payment, Approval, and delegation were not rerun. Subsequent read-only queries of the same debt found both reclamations successful. The last reclamation block was **192 seconds** after Approval. The original transaction still had one successful settlement; deliberate replay of the original nonce returned `permit2_nonce_consumed`. The initial script must not be described as passing without failure.

The observation script was subsequently changed to a total 12-minute budget from startup and a maximum scan of 300 blocks. Independent review found that checking only the outer loop allowed slow RPC calls to exceed the deadline. A deadline helper now limits head, block, receipt RPC, complete response bodies, and polling waits to the remaining budget. Five real loopback HTTP checks reproduced failure before the fix and passed afterward; independent rechecking found no remaining issue. The final helper also read-only checked head/block/receipt endpoints for the original Nile reclamation transactions; all passed, without new payments.

The new payer initially received 1 TRX and 10 Atomic USDT, then made two 1 SUN transfers to consume free bandwidth. TRX remained 999998 SUN before and after sponsorship; final USDT was 9 Atomic. No self-funded Approval, staking, or permission changes occurred. Funded wallet keys remain in restricted directories outside Git. API keys, private keys, and raw signed authorizations are excluded from public evidence.
