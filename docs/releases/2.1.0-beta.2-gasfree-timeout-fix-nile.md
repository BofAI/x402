# GasFree 默认超时修复、Nile 复测与代码走读

日期：2026-10-19。Gateway 修复提交 `af019c2efc56bc91ec1663cfe0470d17c7dcd572`，
基线 `1dcd07a7626dbc06f25a03c0a43b83a713db7994`。两个 SDK 包仍是 npm registry 的
`2.1.0-beta.2`，Core `2.28.0`、Agent Wallet `3.0.0`；没有重新发布 SDK 或部署外围服务。

## 修复结果

TRON `exact_gasfree` 的 verify/settle 现在分别使用独立预算，默认为
`max(240000, X402_GATEWAY_FACILITATOR_TIMEOUT_MS)`，完整响应体也受限。
`X402_GATEWAY_GASFREE_TIMEOUT_MS` 可以显式覆盖，包括较短值。
预算根据实际匹配的付款要求选择，兼容 Exact/GasFree 混合 provider；普通 Exact、
资源代付及入站 body/header 窗口保留原有语义。GasFree 无需再提高全局超时才能等待结算。

该修复针对默认十秒提前终止。它不增加自动补交付状态机；显式短覆盖、长时间故障、
客户端断开或进程退出仍可能留下未知结算，不能根据 504 直接创建替代付款。

## 资源观察失败及后续确认

资源 payer 为 `TSL8Ru7GdbHoCxfXfaPNMDTRkdW1cdWnnV`，owner 为
`THuJK6PNaXibaQhxUdqUXczU57Y8EKhpex`。ENERGY 质押委托额为 461966933 SUN，
BANDWIDTH 为 601873881 SUN，最终均全额回收。

**原短观察窗口内尚无回收，原脚本以 `reclaim not observed yet` 退出失败。**
该初始报告已保留。付款与上游交付此前已成功，因此没有重跑付款、Approval 或再次委托。
随后只读续查同一原债务，发现两笔回收均成功；最后回收区块在 Approval 后 **192 秒**。
再按原交易查询一次成功结算，故意重放原 nonce 得到 `permit2_nonce_consumed`。
不能把最初脚本写成一次无失败通过。

观察脚本后续改为启动后 12 分钟总预算，并限制扫描最多 300 块。
独立走读指出仅检查外层循环会使慢 RPC 超过截止时间；已新增期限辅助函数，将 head、block、
receipt RPC、完整响应体与轮询暂停全部限制在剩余预算内。5 项真实 loopback HTTP 检查
先复现失败，修复后通过，独立复核确认无剩余问题。最终辅助函数还只读检查原 Nile 回收交易的
head/block/receipt 三个接口，全部通过，没有新增付款。

新 payer 初始转入 1 TRX 和 10 Atomic USDT，再转出两次 1 SUN 消耗免费带宽。
代付前后 TRX 均为 999998 SUN，最终 USDT 为 9 Atomic；未自费 Approval、未质押或修改权限，
有余额钱包密钥保留在 Git 外受限目录。API key、私钥和原始签名授权不进入公开证据。
